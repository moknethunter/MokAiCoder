# تشغيل محادثة MokAiCoder

## OpenRouter المجاني

1. أنشئ مفتاح API في [إعدادات OpenRouter](https://openrouter.ai/settings/keys).
2. انسخ `.env.example` إلى `.env` وأدخل المفتاح في `OPENROUTER_API_KEY` على جهاز التشغيل أو في إعدادات أسرار الاستضافة. ولّد رمز دخول مستقلًا للمحادثة باستخدام `node -p "require('node:crypto').randomBytes(24).toString('hex')"` وضعه في `MOKAI_CHAT_TOKEN`.
3. شغّل التطبيق باستخدام `docker compose up -d --build`. للتشغيل المباشر استخدم Node.js 24 ثم `npm ci` و`npm run build` و`node --env-file=.env dist/index.js`.
4. من واجهة MokAiCoder افتح **المحادثة** وأدخل رمز الوصول الذي ولّدته. اختر **OpenRouter** ثم `openrouter/free` وأرسل سؤالًا.

يختار `openrouter/free` نموذجًا من المتاح مجانًا وقت الطلب. يخضع الحساب وحدود التوافر لسياسة المزوّد. يمكنك تعيين قائمة نماذج مفصولة بفواصل في `OPENROUTER_FREE_MODELS`. يقبل هذا المزوّد الموجّه المجاني والنماذج المنتهية بـ `:free`.

## Ollama المحلي

شغّل Ollama ونزّل نموذجًا مثبتًا، مثل `ollama pull qwen2.5-coder:7b`. اضبط `OLLAMA_BASE_URL=http://127.0.0.1:11434/v1/` إذا كان الخادم يعمل مباشرة على الجهاز نفسه. في Docker، استخدم عنوان خدمة Ollama الذي تستطيع حاوية MokAiCoder الوصول إليه، مثل `http://ollama:11434/v1/` عند وجود الخدمتين على شبكة Docker نفسها. تظهر النماذج التي يعيدها Ollama في قائمة الاختيار.

## مزوّد مدفوع

اضبط `PAID_AI_API_KEY` و`PAID_AI_BASE_URL` بعنوان HTTPS يدعم Chat Completions و`PAID_AI_MODELS` بمعرّفات النماذج المسموح بها. مثلًا، عنوان OpenAI هو `https://api.openai.com/v1/`. الإعداد `PAID_AI_TOKEN_PARAMETER` يدعم `max_completion_tokens` و`max_tokens`. يطلب التطبيق موافقة لكل طلب مدفوع.

## الوصول وإرفاق الملفات

ينشر Docker Compose التطبيق على `127.0.0.1` افتراضيًا. للوصول من الهاتف، استخدم واجهة HTTPS على استضافتك لحماية رمز المحادثة. مفاتيح المزوّدين تبقى على الخادم، والمحادثة الحالية تبقى في ذاكرة الصفحة حتى إعادة تحميلها أو قفلها. فحص GitHub يحتاج اسم المالك والمستودع، ويُستخدم مفتاح GitHub إذا احتاج المستودع إلى مصادقة أو إلى حصة API أعلى.

بعد الفحص، يمكنك تحميل قائمة الملفات وإرفاق مقتطف من ملف واحد. يحتاج إرفاق ملف إلى مزوّد سحابي موافقة لكل طلب. ينقّح الخادم الرموز المهيأة وأنماط الأسرار المعروفة، ويُنصح باختيار المقتطفات التي يسمح مالك المستودع بمشاركتها.

## Grok من xAI

اضبط `XAI_API_KEY` على الخادم. اترك `XAI_MODELS` فارغًا لعرض معرّفات النماذج من xAI، أو حدّد معرّفًا واحدًا أو أكثر يفصل بينها فاصلة. يقبل طلب المحادثة النماذج الموجودة في قائمته فقط. قد يمنحك مزوّد الخدمة رصيدًا مجانيًا، ويعامل MokAiCoder طلبات Grok على أنها قابلة للخصم من رصيد API.

في المحادثة اختر النموذج الأساسي ثم **المزوّد المراجع**. مثلًا، اجعل Grok يكتب المسودة، وOpenRouter يراجعها، ثم يرد Grok بناءً على المراجعة. يمكنك اختيار Ollama للمراجعة أيضًا. أكد مشاركة المحادثة والمسودة عند وجود مزوّد سحابي. يعمل اختيار **دون مراجع** كمحادثة مع النموذج الأساسي وحده.

## تعديل ملفات المشروع

1. من المحادثة افتح **تعديل ملف مشروع**. اختر المستودع المهيأ أو مجلد المشروع على جهاز الخادم. اكتب مسار الملف داخل المشروع مثل `src/example.ts` واضغط **فتح الملف**. يمكنك فتح ملف نصّي موجود أو اقتراح إنشاء ملف جديد. الحد الأقصى 8000 محرف للملف.
2. صف التعديل المطلوب في المحادثة. راجع محتوى الملف الأصلي والمقترح. يمكنك تحرير الاقتراح قبل الحفظ.
3. إذا اخترت GitHub، يرفع زر الحفظ المحتوى المعروض إلى فرع `mokai/edit-…`. افتح المقارنة التي يعرضها التطبيق لإنشاء طلب دمج. إذا اخترت مجلد الجهاز، يكتب زر الحفظ الملف داخل المجلد المخصص. أعد فتح الملف إذا تغيّرت نسخته أثناء المراجعة.

يستخدم GitHub المستودع والفرع المحددين في `GITHUB_OWNER` و`GITHUB_REPO` و`GITHUB_BRANCH`. لإتاحة الرفع اضبط `MOKAI_GITHUB_WRITE_TOKEN` بتوكن محدود لهذا المستودع وبصلاحية **Contents: Read and write**. عند ضبط `GITHUB_TOKEN` يطلب فحص المستودع رمز وصول MokAiCoder. يحتفظ GitHub بحالة الفرع وتاريخ تعديله، ويتولى المستخدم إنشاء طلب الدمج من صفحة المقارنة.

اضبط `MOKAI_WORKSPACE_ROOT` على مسار مطلق لمجلد مشروع مخصص يديره صاحب الخادم. يمكن للجهاز استضافة MokAiCoder على الشبكة المحلية، أو مشاركة مجلد مشروع موثوق مع الخادم عبر نظام التشغيل. مع Docker، اربط المجلد عبر bind mount واضبط المتغيّر على مساره داخل الحاوية، وامنح مستخدم الحاوية صلاحية القراءة والكتابة في مجلد المشروع. توفير مجلد محلي يتيح الوصول فقط للمستخدمين الذين يملكون رمز الخادم.

## استخدام هاتف آخر

افتح الرابط نفسه عبر HTTPS من المتصفح، أو اختر **خادم MokAiCoder** في تطبيق أندرويد. يحتاج الهاتف إلى عنوان الخادم ورمز وصول MokAiCoder فقط. مفاتيح OpenRouter وxAI وGitHub تُدخل في بيئة الخادم. اضبط المهلة في الوكيل العكسي على أكثر من 180 ثانية لوضع التعاون عبر البث. واجهة المتصفح تدعم فتح الملفات ومعاينتها وحفظها.
